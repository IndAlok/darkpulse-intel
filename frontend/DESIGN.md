# Desk design

DarkPulse is one dark investigator desk. These tokens are the visual system. Do not replace them with a generated theme.

| Token | Value | Use |
|---|---|---|
| bg | `#070b10` | Page background |
| surface | `#0e1620` | Sidebar, panels, header |
| raised | `#15202b` | Selected row, nested block |
| border | `#243140` | Dividers and control edges |
| ink | `#e7eef4` | Primary text |
| muted | `#8aa0b2` | Secondary text |
| teal | `#2ee6c7` | Healthy status, current nav, focus ring |
| navy | `#9ec5ff` | Source labels and place links |

Type is the system sans. Identifiers use `ui-monospace`. Status colors stay semantic: teal healthy, amber never run, red failed or critical.

Tables stay tables. A panel holds one task. Do not add a hero, a fake metric, glass, gradient text, or a new accent.
